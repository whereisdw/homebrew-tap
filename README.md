# Dawon Labs Homebrew tap

```sh
brew install whereisdw/tap/lidnight
```

- **Lidnight** — keeps a MacBook awake with the lid closed while AI agents work, then sleeps. https://lidnight.app
- **Lidnight Limits** — Claude Code and Codex usage limits in the menu bar, free & open source. https://github.com/whereisdw/lidnight-limits

  ```sh
  brew install --cask whereisdw/tap/lidnight-limits
  ```

The app updates itself; `brew upgrade --cask lidnight` also works. This tap is updated automatically on every release.
